Case Study 01

Campus Dining Portal: WCAG 2.1 AA Remediation

📍 University of Denver · Sodexo📅 2024⏱ 6-week sprint
WCAG 2.1 AAUSWDSReactARIAJIRA

The problem

The campus dining portal served thousands of daily users but had never been audited for accessibility. Screen reader and keyboard-only users were locked out of core features. I initiated and led the full remediation.

Process

1

Automated and manual audit

Lighthouse and axe DevTools plus keyboard-only and NVDA walkthroughs of every user flow.

2

JIRA backlog with user stories

Converted every violation into a user story tied to its WCAG success criterion. Prioritized by user impact.

3

Remediation in React

Rebuilt non-compliant components using USWDS-aligned patterns. Added ARIA roles, labels, and focus management.

4

Validation and release notes

Tested with NVDA, VoiceOver on iOS, keyboard-only across Chrome, Firefox, and Safari before shipping.

// Before: screen reader says "button"
<button onClick={handleFilter}><FilterIcon/></button>

// After: WCAG 4.1.2 compliant
<button aria-label="Filter by dietary preference" aria-expanded={isOpen}>
  <FilterIcon aria-hidden="true"/></button>
I didn't treat this as a compliance checklist. I treated it as part of building something that actually works for everyone.
